# Router model card

- **Model:** Multinomial Naive Bayes with add-one smoothing.
- **Artifact:** `models/router.json`; regenerated at application startup from `TRAIN` in `app.py`.
- **Labels:** keyword, dense, hybrid, sql, tool.
- **Training examples:** synthetic, manually authored requests. Exact training count is stored in the artifact.
- **Intended use:** choose a retrieval strategy in this offline demonstration.
- **Out of scope:** production routing, safety/authorization decisions, calibrated confidence, or real enterprise traffic.
- **Evaluation:** deterministic stratified eight-example holdout, generated by `experiments/evaluate.py`. See the measured report alongside this file.
- **Known failure modes:** small data, lexical ambiguity, template leakage, no probability calibration, no domain shift study. Authorization is separate application code and never delegated to the classifier.

Do not interpret class probabilities as confidence that the final answer is correct.
